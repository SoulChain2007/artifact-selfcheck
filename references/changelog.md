# 变更台账（这个 skill 自己的版本史）

格式固定一行，字段不许省。没有「触发台账行」的改动不许写进来（= 凭想象加规则）。

```
<version> | <date> | <触发的台账行: batch/class/date 或 用户口径原文> | <改了哪个文件的哪一处> | <合并/删除的等量旧规则> | <verify: 下一轮谁+哪条命令+期望读数> | <author 执行者>
```

## 阅读约定（公开发行版）

- **「第 N 批」**是维护者在真实交付里推进的批次编号。它是失效记录的坐标，用来证明「每条规则背后都有一次
  真实事故」，不是虚构的示例。
- **「某项目」**= 该批次实际被检查的那个产物库（设定集 / 代码库 / 文档集）。只保留规模与读数，不留身份。
- 实体名、内部文件名、私有环境变量、项目侧路径已在公开发行版中脱敏为占位或通称；判据与失效族本身一字未改。
- 本文件与 `SKILL.md` 的「硬规则」「起手不变式」互为索引：规则里写的实测案例，都能在这里找到出处。
