# 自检方法：范围、输入快照、真实入口与返工

目录：画像；操作；证据；流水；输出与自学。3.0模式以 [quality](quality.md) 为准。
公开包的 [2.8迁移摘要](history-v2.8/selfcheck.md) 只说明版本边界，不包含私人项目原始审计记录，也不覆盖本版合同。

## 1. 任务画像与加载

提取：产物类型；本次交付范围与档位；承重结论；外部结论是否存在及主题词。
quick 是可逆局部任务；partial 是声明分区；full 是声明范围上的完整验收或高失败代价交付。
小文件也可能高风险，例如Hook或存档迁移；大项目的一次文案修改不自动变full全库审计。
用户的完整验收要求不可自行降档。阶段出口、跨模块改变或风险上升时重新定档，
不因连续两轮partial就机械全库重跑；记录累计未覆盖范围，阶段出口收口。
quick只加载对应领域与模式；full也只读适用方法，不把历史库、世界设定探针全部加载。

## 2. 五步

1. **冻结输入**：记本轮根目录、分支/提交或文件哈希、时间与当前输入。项目运行中若被其他执行者修改，重新取相关快照，旧读数不覆盖。
2. **取分母**：用户需求/验收规格定产品范围；源码与schema核当前契约；外部规范核外部技术事实。不同来源冲突如实列出，不能拿“代码就是这样”当需求正确。
3. **生成清单**：A产物域，B最近相关class，C本轮风险，D实际覆盖缺口。B/D无适用项可明确为空，不为凑新颖度造检查。
4. **取读数**：先确认命令在正确路径、正确版本真实执行，再记输入、输出、退出码与判断。测试不能零样本；负对照不能走未使用分支。
5. **对账返工**：应有/实有/未验证/范围外分开，缺陷按风险排序。返工写负责人角色、动作、落点、命令/观察及期望。修后另取快照并回归，禁止覆写修前结果。

有效稳定的测试可跨轮复用；复跑结果必须关联当前输入与工具版本。无新信息不是失效证据，
需要看是否覆盖相关样本、是否仍能拒绝已知缺陷；别为了报告“有进步”替换有效回归。

## 3. 证据纪律

- 输出须承载结论：全文件没改用完整内容哈希，不能只哈希ID行；跨口径先证明同口径。
- 小计数也从实际输出计算；引文回原文，不能把他人的转述当原件。
- 否定断言必须检查完整查询范围和所有相关输出；长日志落盘，报告给总量、命令、定位与截断声明，不强制粘贴全部日志。
- 抽样记录范围、样本标识、种子/规则、实际样本量与未查项。重复标识不能充数，裸ID不算逐条读数。
- 人工观察、图像、文档阅读可作对应证据，写清观察步骤、对象与结果；不要虚构可自动判艺术观感的命令。
- 编译、逻辑测试、初始化集成、注入、实机效果分别声明。既有测试二进制通过不证明当前源码已重新构建。
- 失败时先看样本，区分设计有意状态与缺陷；该新方法的历史2.7实验独立准入待补，不靠历史自述放行。
- 变异只在隔离副本/夹具，读回证明已生效；拒绝原因须命中目标问题。检查器崩溃不计检出。

修复回归覆盖本文件元数据、实际消费者、相邻配置/枚举边界与活引用；旧写法搜索逐项分类，
历史快照保留不要求0命中。世界条目正文ID是否需入依赖边，由该项目schema决定，不强加代码域。

## 4. 流水的结果协议（3.0迁移）

```text
python scripts/pipeline.py --config selfcheck_pipeline.json --stamp pipeline-run.json --json
```

配置中的相对路径按配置文件所在目录解析，不再按basename偷偷换成另一个同名脚本。
每项为 `name/script/args`；占位符如 `{root}` 必须有实际值。Python运行时需要实际可执行。
CLEAN=成功执行且无发现；FIND=成功执行且报告目标发现；ERROR=依赖/输入/启动/解析/崩溃/留痕失败。
非零退出码不能单独证明FIND。新检查器返回发现码1并输出独立行 `ARTIFACT_SELFCHECK_FIND`，
或JSON对象含 `selfcheck_protocol: 1, status: "FIND"`；stderr须无运行错误。
旧检查器通过每项 `finding_marker`（独立行）与 `finding_codes` 显式适配；无协议的rc1保守记ERROR。
配置为空、stamp不能写、脚本缺失都不能成功。CLEAN/FIND/ERROR是检查执行状态，
流水无ERROR仍可能有待修缺陷，不能把exit0写成“产物全通过”。

脚本只会识别其实现支持的语法。世界YAML探针及旧启发式如无本轮有效样本验证，
只能提供线索，不可单独支撑全库健康。域不适用时不执行、不假装通过。

## 5. 输出与自学

quick：画像、范围内证据、未做项、反查、评分/适用范围与反馈行，可并入已有任务记录。
partial/full：独立报告与台账，保留证据索引、对账、缺陷/返工、覆盖、来源适用性、复核状态和下一轮重点。
所有档位答适用九问，未做写原因；无需机械复制十一节。
反馈同时记保持通过的对照与新发现；更新目标锚的覆盖登记。
自学变更按 [learning](learning.md) 准入；用户授权维护批允许多个独立修复，不用“只改一处”阻断已授权工作。
