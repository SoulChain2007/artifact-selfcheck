# 范围、分片与检出能力

## 1. 深度
本轮承重变更与关键入口按声明范围完整检查；非承重稳定内容可用明确抽样。声明检查整个系统时不能只报告局部样本。文件数量不自动决定档位。

## 2. 有效反例
在隔离副本或夹具中制造目标缺陷，读回确认缺陷确实生效，再运行实际检查器。记录输入、预期拒绝原因、实际输出和成功对照。崩溃、解析错误或走不到目标分支不算检出。
quick至少反查一条通过断言；partial/full按合同用有效灵敏度样本。稳定回归可以跨轮复用，但读数须关联当前版本。

## 3. 分片
按依赖、章节、资产系列或风险分区分片，记录每片的分母、已查与未查。阅读量和项目结构决定片大小，不把固定文件阈值当成跨域定律。
跨模块链路在阶段出口收口；不因固定轮数到点就机械重扫全库，也不让历史缺口无限顺延。

## 4. 报告
信息应足以复核：范围、输入版本、样本、命令或观察、结果、失败处置与限制。报告形状可变，不能删掉承重信息。方法变化给出原因、前后对照与回滚点。
