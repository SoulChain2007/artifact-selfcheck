# 世界设定域专用探针（原 `selfcheck.md` §4.6–§4.10）

适用范围：**设定集 / 世界设定域**产物（与 `domains.md` 的标注一致）。该域产物每轮按各节要求执行；
其他域的产物遇到本文件，⛔ 不许假装跑过——在报告「未做项」写明「域不适用 + 原因」即可。
通用探针（§4.5 随机抽样溯源 / §4.11 覆盖面声明 / §4.12 自检流水）仍在 `selfcheck.md` 主干，对所有域强制执行。

## 4.6 世界内可达性验证（该域产物每轮至少一条）

字段齐全只说明条目**自己**写完了；**可达性**说明它**接进了世界**。所以每轮再抽一条"世界里的东西"
（武器 / 材料 / 食物 / 器物 / 载具 / 药…），**假设自己是这个世界的人**，问一句：

> 我要得到它、或了解它，得走哪几条路？

每条路写成一条**完整逻辑链**（谁 → 去哪里 → 找谁 → 用什么 → 得到什么），**至少两条**。
例：抽到一张武器 ⇒ ① 去某地区经某渠道购买；② 击杀某异兽取某材料自行制作。

然后**逐跳对账**（这是本方法的判据）：链上每个节点都要在产物里有**对应条目**、且**可溯源**；
断在哪一跳就派哪一跳的返工件。**链断 = 内容漏缺**，与"字段没填"是两回事。

工具：`scripts/chain_walk.py --root <产物根> [--id <条目>] [--n 2] [--seed <固定种子>]`
—— 它从条目字段里自动生成"购买/交易链"与"自制链"两条骨架，并**逐跳解析**名字到条目，
输出每跳的 ✅/❌ 与命中的条目 ID。

⛔ 只写一条链 = 没验（用户明确要"不止一条"）；⛔ 链上节点解析不到却写成"可获得" = 幻觉；
⛔ 把"这条能拿到"写成"全库都能拿到" = 越界（抽样只对抽样框负责）。

## 4.7 概念理解链验证（该域产物每轮至少一个概念）

「东西能不能拿到」之外还有一层：**概念能不能被这个世界的人理解**。抽一个**世界观层概念**
（法则 / 判据 / 制度 / 工法 / 术语；⛔ 不含给玩家看的机制槽位），问：**这个世界的人凭什么理解它？**
三条链都要闭合，缺一条就是一个真实缺口：

| 链 | 问句 | 断了意味着 |
|---|---|---|
| **A 定义链（向上）** | 它依赖哪些更基础的概念？能一路追到**原词**吗？ | 概念没有落点（成环 / 断在半路） |
| **B 传授链（横向）** | 这个世界的人**从哪儿学到它**？有学府 / 流派 / 职业 / 法令 / 典籍与它相连吗？ | 这概念只存在于作者脑子里，**不在世界里** |
| **C 落地链（向下）** | 有具体实例依赖它吗？ | 读得懂但用不上（悬空抽象） |

工具：`scripts/concept_walk.py --root <产物根> [--id <概念>] [--n 2] [--seed <固定>]`
（默认排除 `cards/` 这类机制树 —— "世界的人怎么理解"只对世界层概念成立；`--include-mechanics` 可纳入。）

实测价值（某项目抽 200 个世界层概念）：A 闭合 67/70、**B 只闭合 4/70**、C 22/70、三条全闭 3/70 ——
**B 是系统缺口**：世界法则是真的，但没人知道这个世界的人凭什么知道它。
⛔ 只验 A 会得出"概念很完整"的错误结论；**B 才是这个世界能不能被理解的关键**。

## 4.8 结构审计五问（把"用户找漏洞的元手法"机械化）

用户每次都是从**一个具体提问角度**切进来的，把这些角度固定成方法就得到本节的五问
（工具：`scripts/struct_audit.py --root <产物根> [--ledger <台账>] [--scale <字段=值>]`）：

| # | 问法 | 发现什么 | 实测读数（某项目） |
|---|---|---|---|
| ① **对本子自身提问** | 自检台账用的 `class` 码是否都在**封闭词表**内？ | 判据自身的漏洞：发明同义写法 ⇒ 跨轮"同类 ≥2"永远统计不出来 | **22 个码里 8 个不在词表内** |
| ② **跨条目对撞** | 同一个实体（同名）在不同条目里被赋予**不同取值**吗？ | 双真相源、同名不同物 | **5 处**（含同一个武器名落在两个不同分类） |
| ③ **命名法一致性** | 有纯英文 slug 当名字、或中英混用吗？ | 命名体系漂移（世界里的人不会这么叫） | 纯 slug **24 条**、中英混用 **46 条** |
| ④ **规模自洽** | 设定文案里的数量级与库内条目数对得上吗？ | 数量漏缺（声称 40 张、实存 13 条） | `rarity=S` 库内 **13** vs 文案「≈40 张」 |
| ⑤ **时序闭合** | 状态字段（现存/失传/新创/在研）出现过"非现存"吗？ | 时间维度没落地（历史维度形同虚设） | 状态字段只有「现存」一个取值（**295+8** 条） |

⛔ 五问都要跑；只跑①会漏内容、只跑②~⑤会漏判据自身。
**①（判据基础设施自检）是本 skill 唯一对"自己"发问的一条**，也是"自检为什么没发挥效果"的根因检查：
判据的元数据（词表 / 检查器名 / 编号）一漂，后面所有统计都会悄悄失真。

## 4.9 锚点级引用解析 + 来源支撑性抽检（补 L5 可验证性）

用**透镜覆盖率矩阵**找缺口：把已有的检查器铺到六条透镜上，最薄的是 **L5 可验证性**（引用"解析得到"
不等于"撑得住那句话"）。于是补两个探针（工具：`scripts/anchor_and_support.py`）：

| 探针 | 问句 | 当场命中（某项目） |
|---|---|---|
| **A 锚点级引用解析** | 引用写成 `docs/54 §1.15` 时，**文件解析得到 ≠ 那一节还在** —— 文档重构/改编号后，编号命中、节号却飞了 | 1793 条带 §锚点的引用里 **7 处悬空**（全指向同一份文档的同一节） |
| **B 来源支撑性抽检** | 「来源存在」≠「来源支撑我这句话」：条目名是否真出现在**被引文件**里 | 抽 40 条：**具名类 12/20**、抽象类 7/20（后者不判生效） |

⛔ **B 必须按类型分档**（这是本方法最容易错的地方）：抽象条目（`Seal × Monster`、`气质原型 · 侠气`）
的名字本来就不该出现在被引文档里，拿名字判它就是误报 —— 实测首版 40 条里 21 条"未命中"，
**绝大多数是抽象类**，直接判 FAIL 会冤枉一半。所以：**具名类判据（≥60%）＋抽象类只作人工判读**。

外部依据（已过准入闸门）：CitePrism（arXiv **2605.16000**）原文 "Citation context…affect whether
a reference **appropriately supports a local claim**"；VeriCite（arXiv **2510.11394**）证明行内引用核验
能减少幻觉、便于人工复核。锚点类检查**未命中先例** ⇒ 自创，按规则标 `weak`。

## 4.10 深度四问（补 L2 分母深度 / L3 跨层一致 / 可证伪性 / L6 抽样纪律）

工具：`scripts/deep_audit.py --entries <根> [--mirror <镜像yaml>] [--reports <报告目录>]`

| # | 问法 | 判据 | 当场读数（某项目） |
|---|---|---|---|
| ① **设定 ↔ 机读镜像** | 设定说这类卡的 `allowed_ops` 是这 20 个，**游戏侧的表也是这 20 个吗**？ | 逐字段（列表按集合比、标量按值比）**漂移必须为 0** | 18 个类 → **漂移 0**（生成器同源，健康） |
| ② **反证/边界闭合** | 这条**判据**有"不许什么"的边界或反例条目吗？ | **只对 judge 要求**（law 是公理、bound 自身即边界，豁免） | 3 个 judge → **2 个无边界引用**（真缺口） |
| ③ **一天的生活链** | 吃 / 住 / 交易 / 纠纷 / 病 / 葬 —— 每环有条目吗？有世界内落点吗？ | 每环 ≥N 条 + 落点字段存在 | 六环**全通**（12/18/3/6/8/6 条，落点齐全） |
| ④ **分母深度** | 三套外部分母"整类未枚举=0"只说明**每类有一个代币**；每类多厚？ | ≤2 条 = 代币覆盖，**列入人工判读**（单例类型如历法/大陆豁免） | 100 类中 **17 类仅 ≤2 条** |
| ⑤ **抽样纪律** | 报告按自己的抽样声明说话了吗？ | 出现"抽N/池M / 抽样声明 / 穷尽 / 全量读数"即算声明；**没声明却说"全库健康"⇒ 越界** | 最近 4 份报告 **4/4 有声明** |

⛔ **本节首版 55 项发现里绝大多数是假阳性**，三个判据都被样本推翻（记下来当教案）：
① "落国 0"——`food` 的落点字段其实叫 `region`；② 五环落点字段各不相同
（`building→settlement`、`medicine→practitioner`、`rite→registry`、`verdict→arbiter`），硬找 `nation` 全错；
③ `continent/chain/calendar` 是**天然单例**，按"厚度"判就是误报；④ `抽样声明` 只认"抽N/池M"会漏掉写"穷尽"的报告。
**这三处修正把 55 项降到 19 项** —— 「判据 FAIL 先看样本再调判据」不是口号，它每天都在救假阳性。

外部依据（已过准入闸门）：边界值分析（arXiv **2501.14465**）"…**intricate or highly variable boundaries**"；
世界内/叙事层视角（arXiv **2306.06794**）"A blind spot for large language models: **Supradiegetic** linguistic
information"；跨层约束（arXiv **2606.18421**，仅标题级读数 ⇒ 标 weak）。
